# Hari Krishna Digiventi — Portfolio

A responsive dark-mode portfolio built with plain HTML, CSS, and JavaScript. No framework or build step required.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser, or use VS Code's Live Server extension.
3. Edit `index.html` to add your email, real GitHub/LinkedIn URLs, repository links, and verified certificates.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your real email address (both mailto and `data-email`).
- Replace generic `https://github.com/` links with your actual profile/repository URLs.
- Replace generic `https://www.linkedin.com/` with your profile URL.
- Add your resume PDF to this folder named `resume.pdf`.
- Update any project descriptions/statuses to match what is implemented and publicly available.
- Add only verified certificates and credentials.
- Optional: replace the placeholder notes with real blog posts.

## Deploy on GitHub Pages
1. Create a GitHub repository, for example `hari-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and optionally `resume.pdf`.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for the deployment URL shown on the Pages settings screen.

You can also deploy the folder using Netlify Drop or another static host. No backend is required.
